# DIVA Visualization Demo

A web application for exploring and visualizing analytical provenance data using the DIVA ontology.

## Overview

This application provides interactive visualizations of user exploration processes within visualization tools. It uses SPARQL queries to extract provenance information and displays it through multiple visualization types.

## Features

1. **Query Selection**
    - Dropdown menu for competency questions (defined in [here](../sparql-examples/README.md))
    - Dynamic loading of SPARQL queries
    - Query result caching

2. **Visualization Views**
    - SPARQL query display with syntax highligthing
    - Results table
    - Temporal sequence and relationships view supported by the Muvin tool
    - A bar chart for summarized information

## Dependencies

- [Vite](https://vite.dev) for the dev server and the build
- [Muvin](https://www.npmjs.com/package/muvin) for the temporal sequences view
- D3.js, Bootstrap, Prism.js and SweetAlert2 (loaded from CDNs)

Check all dependencies in the [package.json](package.json)

## Run

```bash
npm install
npm run dev      # dev server with hot reload
npm run build    # static site in dist/ (what GitHub Pages serves under /vis/)
```

The app never calls a SPARQL engine: the results of the competency questions are precomputed in `public/api/` and committed. The GitHub Actions workflow only runs `npm run build`.

## Updating the data

When the data, the ontology or a query changes, regenerate `public/api/` with [Corese-Command](https://corese-stack.github.io/corese-command/v4.6.1/install.html) (`corese` on the PATH, or `CORESE_JAR=/path/to/corese-command-standalone.jar`) and commit the result:

```bash
npm run fetch-data
```

To add a competency question, add its `.rq` file to `../sparql-examples` and an entry to `config.json`, then run `fetch-data`.
