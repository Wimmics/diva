The DIVA ontology models analytical provenance by representing the relationships between data, visualizations, user interactions, and the insights and rationale derived during exploration. It is organized into the following modules:

- **Data:** describes data sources and queries.
- **Visualization:** represents views, visual encodings, and interface elements.
- **Interaction:** captures analytical tasks, user actions, view manipulations, and input events.
- **Insight and Rationale:** represent users’ interpretations and reasoning through annotations.

These elements are connected through provenance relationships, enabling user exploration paths to be represented as RDF knowledge graphs. DIVA is complemented by a SKOS thesaurus that provides controlled vocabularies for visualization and interaction concepts: see the [DIVA Thesaurus](../thesaurus/index.html).
