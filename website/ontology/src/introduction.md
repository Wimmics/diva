The DIVA ontology (Data, Interaction, Visualization, and Analysis) provides a semantic model for representing user activity and analytical provenance in interactive visualization systems. Existing approaches often rely on system-specific formats, limiting interoperability, reuse, and automated analysis. Building on Semantic Web standards, including PROV-O, DCAT, and SKOS, DIVA models exploration paths, datasets, visualizations, user interactions, and analytical insights as knowledge graphs. Its goal is to facilitate the systematic analysis and comparison of user exploration behaviors, providing a foundation for reproducible analysis, visualization recommendation, and adaptive visualization systems.
